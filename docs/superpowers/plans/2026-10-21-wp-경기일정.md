# WordPress 경기 일정 페이지 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** barosportstv.com(WordPress)에 서버에서 완성된 HTML 로 나가는 5일치 경기 일정 페이지를 만든다.

**Architecture:** 프리베이크가 `assets/data.js` 를 Node `vm` 에서 그대로 돌려(TZ=Asia/Seoul) 화면용 JSON(`data/wp/`)을 만들고 GitHub Pages 에 함께 배포한다. WordPress 테마는 WP 크론으로 그 JSON 을 받아 옵션에 저장하고, 페이지 템플릿이 PHP 로 HTML·JSON-LD 를 출력한다. 판정 로직은 `data.js` 한 곳에만 있다.

**Tech Stack:** Node 24 (`node:test`, `node:vm`), PHP 7.4+ / WordPress 6+ (테마), GitHub Actions + Pages.

**Spec:** `docs/superpowers/specs/2026-10-21-wp-경기일정-설계.md`

## Global Constraints

- 시간대 **Asia/Seoul 고정**. 날짜 키 형식 `YYYY-MM-DD`.
- 판정 로직(상태·시각·한글 팀명·등급·정렬)을 PHP 로 다시 쓰지 않는다. PHP 는 리그 필터 3줄 규칙만 가진다: `all` 전부 · `top` = `tier === 1` · 그 밖 = `slug` 일치. 기본값 `top`.
- 테마 `wp-theme/barosportstv/assets/tailwind.css` 에 **없는 클래스 금지** — 쓰기 전에 grep 으로 확인, 없으면 있는 클래스로 대체. `npm run build:css` 를 돌리지 않는다.
- 정적 사이트 `assets/data.js`·`assets/app.js` 는 수정하지 않는다. `npm test` 의 기존 57개는 그대로 통과해야 한다.
- 한 쪽 **150행**, JSON-LD **최대 100건**, 오래된 데이터 기준 **2시간**, 크론 **10분**, 첫 동기 요청 타임아웃 **5초**.
- 데이터 주소 `https://peter77-tech.github.io/barosportstv/data/wp/` (필터 `bstv_schedule_source`).
- 저장소는 **공개**다. 커밋 전에 비밀값이 없는지 본다. `.bak_*`·zip 은 커밋하지 않는다.
- 브랜치 `main` 에 push 하면 배포(full 회차, 29분)가 돈다 — push 는 Task 6 에서 한 번만.
- 테마 버전 `0.1.1` → **`0.2.0`** (`style.css`·`BSTV_VERSION`).

## Review Focus

1. **한국 자정 근처 경기** (UTC 15:00~15:59) — KST 다음 날 파일에 들어가야 한다. → Task 2 테스트 `kst_midnight`.
2. **GitHub 이 오류·HTML·잘린 JSON 을 줄 때** — 저장된 데이터를 그대로 둔다. → Task 3 테스트 `valid_day_rejects`.
3. **크론이 멈춰 데이터가 오래됐을 때** — 안내문 + 「진행 중」 대신 「확인 필요」, JSON-LD 미출력. → Task 3 테스트 `is_stale`, Task 4 화면 확인.
4. **이상한 쿼리** (`?d=1999-01-01`, `?l=<script>`, `?p=-3`) — 기본값으로 돌아가고 그대로 출력되지 않는다. → Task 3 테스트 `sanitize_request`.
5. **주요 리그가 0경기인 날** — 빈 목록 대신 「주요 리그 경기가 없습니다 — 전체 보기」 안내. → Task 3 테스트 `filter_top_empty`, Task 4 화면 확인.
